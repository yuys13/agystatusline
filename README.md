# agystatusline

[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/yuys13/agystatusline)

`agystatusline` is a highly customizable terminal status line generator designed for **Google Antigravity CLI**. It parses the session telemetry JSON streamed to its standard input and renders a beautifully formatted, color-coded, and Powerline-compatible status line.

## Installation

You can install `agystatusline` directly using Go:

```bash
go install github.com/yuys13/agystatusline@latest
```

Make sure that your Go bin directory (typically `$GOPATH/bin` or `~/go/bin`) is included in your system's `PATH` environment variable.

## Integration with Google Antigravity CLI

To configure Google Antigravity CLI to use `agystatusline` as its status line, update your configuration file (typically located at `~/.gemini/antigravity-cli/settings.json`) to include the following configuration:

```json
{
  "statusLine": {
    "type": "command",
    "command": "agystatusline",
    "stack_with_default": true
  }
}
```

### Options

- **`command`**: Set this to the name or path of the executable (`agystatusline`).
- **`stack_with_default`**: When set to `true`, the default Antigravity CLI status line and the custom status line generated by `agystatusline` will be vertically stacked (stacked on top of each other), allowing you to view both status lines at the same time.

## Customization (TUI Settings Menu)

You can customize the status line layout, widgets, colors, and Powerline separators interactively using the TUI configuration menu.

To launch the TUI menu, simply run `agystatusline` without piping any data into standard input:

```bash
agystatusline
```

### Key TUI Features

- **Live Preview**: The status line preview at the top of the terminal dynamically reflects your changes.
- **Multi-Line Editing**: Easily add, delete, and configure multiple status lines and their associated widgets.
- **Powerline Themes & Separators**: Configure Powerline styles and separators (such as `nord-aurora`) through dedicated menus.

### Configuration Files

By default, your settings are saved to:
`~/.config/agystatusline/settings.toml`

To use or modify a custom configuration file, pass the `--config` flag:

```bash
agystatusline --config /path/to/custom-settings.toml
```

## Payload Persistence (Dump)

If you want other desktop tools, status bars (e.g. Quickshell, Waybar), or monitoring scripts to read Antigravity's live quota, context metrics, and session telemetry, `agystatusline` can persist the raw JSON payload streamed on `stdin` directly to a file:

```toml
# In ~/.config/agystatusline/settings.toml
[payload_dump]
enabled = true
path = "~/.local/share/agystatusline/payload.json"
```

- **Verbatim**: Writes the exact JSON document received from Antigravity CLI without alteration.
- **Atomic Replace**: Safely writes to a temporary file in the destination directory before atomically renaming, preventing partial reads by polling processes.
- **Secure**: Created with `0600` permissions (readable and writable by user only).
- **Default Fallback**: If `path` is empty or omitted, falls back to `~/.local/share/agystatusline/payload.json`.
- **Non-blocking**: Best-effort persistence that never interrupts or delays status line rendering.
